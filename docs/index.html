How this is calculated

Show methodology

Numbers are aggregated lifetime totals since January 1, 2020, pulled monthly from ICPSR's PCMS APIs (curated datasets) and the openICPSR usage endpoint (self-published datasets). Curated entries report data and documentation downloads, unique users, and citing publications. Self-published entries report total downloads and total project-page views only — openICPSR does not expose a per-month breakdown. The dashboard is rebuilt automatically on the first of each month from the latest scrape.

Source code, raw CSVs, and the full schema are on the dashboard's GitHub repository.
